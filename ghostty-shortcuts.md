# Ghostty Shortcuts Reference

## Splits

| Shortcut | Action |
|---|---|
| `Cmd + D` | Split right (vertical) |
| `Cmd + Shift + D` | Split down (horizontal) |
| `Cmd + Shift + Enter` | Zoom/unzoom current split |
| `Cmd + [` | Go to previous split |
| `Cmd + ]` | Go to next split |
| `Cmd + Alt + ↑/↓/←/→` | Go to split by direction |
| `Cmd + Ctrl + H/J/K/L` | Go to split (vim-style) ✦ |
| `Cmd + Ctrl + ↑/↓/←/→` | Resize split by 10px |
| `Cmd + Ctrl + =` | Equalize all splits |
| `Cmd + W` | Close current split/tab |

> ✦ Custom keybind added to config

## Tabs

| Shortcut | Action |
|---|---|
| `Cmd + T` | New tab |
| `Cmd + Shift + [` | Previous tab |
| `Cmd + Shift + ]` | Next tab |
| `Cmd + 1–8` | Go to tab by number |
| `Cmd + 9` | Go to last tab |
| `Cmd + Alt + W` | Close current tab |

## Window

| Shortcut | Action |
|---|---|
| `Cmd + N` | New window |
| `Cmd + Shift + W` | Close window |
| `Cmd + Alt + Shift + W` | Close all windows |
| `Cmd + Enter` | Toggle fullscreen |
| `Cmd + Ctrl + F` | Toggle fullscreen (alt) |

## Text & Clipboard

| Shortcut | Action |
|---|---|
| `Cmd + C` | Copy to clipboard |
| `Cmd + V` | Paste from clipboard |
| `Cmd + Shift + V` | Paste from selection |
| `Cmd + A` | Select all |
| `Cmd + K` | Clear screen |
| `Cmd + Z` | Undo |
| `Cmd + Shift + Z` | Redo |

## Font Size

| Shortcut | Action |
|---|---|
| `Cmd + =` | Increase font size |
| `Cmd + -` | Decrease font size |
| `Cmd + 0` | Reset font size |

## Search

| Shortcut | Action |
|---|---|
| `Cmd + F` | Start search |
| `Cmd + G` | Next search result |
| `Cmd + Shift + G` | Previous search result |
| `Cmd + Shift + F` / `Esc` | End search |
| `Cmd + E` | Search current selection |

## Scrolling

| Shortcut | Action |
|---|---|
| `Cmd + Home` | Scroll to top |
| `Cmd + End` | Scroll to bottom |
| `Cmd + Page Up` | Scroll page up |
| `Cmd + Page Down` | Scroll page down |
| `Cmd + J` | Scroll to selection |
| `Cmd + ↑` | Jump to previous prompt |
| `Cmd + ↓` | Jump to next prompt |
| `Cmd + Shift + ↑` | Jump to previous prompt (alt) |
| `Cmd + Shift + ↓` | Jump to next prompt (alt) |

## Config & Misc

| Shortcut | Action |
|---|---|
| `Cmd + ,` | Open config file |
| `Cmd + Shift + ,` | Reload config |
| `Cmd + Shift + P` | Command palette |
| `Cmd + Alt + I` | Toggle inspector |
| `Cmd + Q` | Quit Ghostty |
